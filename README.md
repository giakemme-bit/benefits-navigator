# Навигатор по льготам (MVP)

Мобильный сайт: человек отвечает на 2 вопроса (год рождения и группа), видит положенные льготы, отмечает полученные и открывает пошаговую инструкцию. Если не получается, пишет оператору в WhatsApp или Telegram.

Без сервера и базы данных. Без аналитики и сторонних шрифтов. ИИН и ФИО не спрашиваются. На устройстве (в `localStorage`) хранятся только группа, сегмент и отметки «Получаю». Год рождения не сохраняется.

## Где править тексты и данные (без программиста)

Все файлы лежат в папке `public/`. После правки на GitHub сайт пересобирается сам за 1–2 минуты.

| Что | Файл |
|---|---|
| Льготы | `public/data/benefits.json` |
| Пошаговые инструкции | `public/data/guides.json` |
| Номер WhatsApp, Telegram, пенсионный возраст | `public/data/config.json` |
| Все надписи на кнопках и экранах (рус.) | `public/i18n/ru.json` |
| Казахский перевод | `public/i18n/kk.json` |

Правила JSON: текст в двойных кавычках, между записями запятая, после последней записи запятой нет. Если сайт после правки показывает «Не удалось загрузить данные», скорее всего, лишняя или пропущенная запятая. Проверить файл можно на jsonlint.com.

### Поля льготы (= колонки таблицы «База льгот»)

| Поле | Колонка | Значения |
|---|---|---|
| `title` | Льгота или услуга | текст |
| `segments` | Сегмент | `child` (до 18), `adult`, `pensioner` |
| `groups` | Группа | `I`, `II`, `III`, `under7` (ребёнок до 7 лет) |
| `childhood` | С детства (необязательная колонка) | `true` только с детства, `false` только не с детства, `null` не важно. Без колонки определяется по названию: «с детства» или «от общего заболевания» |
| `amount` | Размер или суть | текст |
| `howTo` | Как получить | текст |
| `basis` | Основание | текст |
| `source` | Источник | текст |
| `status` | Статус проверки | `Проверено` — без пометки; `Не проверено` — с пометкой «Не проверено»; `Нужно собрать` и `Устарело` — не показываются (список в `hiddenStatuses` в `config.json`) |
| `checkedAt` | Дата проверки | текст |
| `comment` | Комментарий | не показывается на сайте |
| `guideId` | Инструкция (необязательная колонка) | ключ из `guides.json`. Без колонки берётся инструкция, у которой `benefitTitle` совпадает с названием льготы |

### Подробные шаги внутри шага

У любого шага инструкции в `guides.json` можно добавить раскрывающийся блок:

```json
"details": {
  "title": "Подробно: как подать на eGov.kz",
  "steps": ["Откройте сайт eGov.kz.", "Войдите с ЭЦП или по SMS-паролю."]
}
```

### Загрузить таблицу целиком

Экспортируйте таблицу в CSV (Google Таблицы: Файл → Скачать → CSV) и выполните:

```bash
npm run import:csv -- путь/к/файлу.csv
```

Скрипт понимает формулировки таблицы и сообщит о строках, которые не смог разобрать.

- Сегмент: «Ребёнок до 7», «Ребёнок 7-18», «Родитель или опекун ребёнка» → ребёнок; «Взрослый», «Взрослый (работающий)», «Опекун взрослого» → взрослый; «Пенсионер»; «Любой».
- Группа: «I», «II», «III», «I, II, III», «Без группы» (= ребёнок до 7 лет), «Любая», «Зависит от города» (= любая). Текст в скобках не учитывается.

Колонка «Комментарий» на сайте не показывается.

### Контакты оператора

В `public/data/config.json` заполните `whatsappNumber` (только цифры, например `77001234567`) и `telegramUsername` (без @). Пока поля пустые, на экране помощи написано «Контакты оператора скоро появятся».

### Казахский язык

Заполните `public/i18n/kk.json` и добавьте `"kk"` в `languages` в `config.json`. Появится переключатель «Рус / Қаз». Незаполненные строки показываются по-русски.

## Для разработчика

```bash
npm install
npm run dev          # локально
npm test             # логика, данные, совпадение ключей ru/kk
npm run build        # сборка в dist/
npx vite preview --port 4173 &
npm run test:e2e     # путь в браузере на 360 px, 5 касаний
npm run test:a11y    # Lighthouse: доступность ≥ 95 на всех экранах
```

Маршруты на `#` (`#/group`, `#/benefits`, `#/guide/sanatorium`, `#/help`), поэтому сайт работает на любом статическом хостинге без настройки. Деплой на GitHub Pages: `.github/workflows/deploy.yml` (в настройках репозитория: Pages → Source: GitHub Actions). Netlify/Vercel: команда `npm run build`, папка `dist`.

Логика сегментов (`src/lib/logic.js`): возраст = текущий год − год рождения. До 17 включительно: ребёнок; от `pensionAge`: пенсионер. До 6 лет: вопрос о группе пропускается. Ровно 7 (день рождения неизвестен): к I–III добавляется «Ребёнок до 7 лет». Детям вопрос «с детства?» не задаётся.
