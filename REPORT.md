# Отчёт: MVP навигатора по льготам

Дата: 22.11.2026

**Сайт:** https://giakemme-bit.github.io/benefits-navigator/
**Репозиторий:** https://github.com/giakemme-bit/benefits-navigator

## Что сделано

- **5 экранов по макету:** год рождения → группа инвалидности → «Вам положено» → инструкция «Как получить санаторий» (4 шага) → «Нужна помощь». Статический сайт на Vite + React, без сервера и базы данных.
- **Все тексты и данные в JSON** в папке `public/`, их можно править без программиста.
- **Пометка «Суммы и порядок сверяются с официальными источниками»** на экране льгот и в инструкции. У каждой непроверенной льготы значок «Не проверено».
- **Экран помощи** собирает сообщение оператору: тема, группа и текст человека. В WhatsApp текст подставляется в чат. Для Telegram текст копируется, потому что Telegram не умеет вставлять его сам. Пока контакты не заданы, показывается «Контакты оператора скоро появятся».
- **Личные данные не собираются.** ИИН и ФИО не спрашиваются. Ответы и отметки «Получаю» хранятся только пока страница открыта: после обновления всё начинается заново, на устройстве ничего не сохраняется. Есть кнопка «Начать заново».
- **Нет аналитики и сторонних шрифтов**, на сторонние серверы запросы не уходят.
- **i18n:** `ru.json` заполнен, `kk.json` подготовлен с теми же ключами.
- **Загрузка таблицы:** скрипт `npm run import:csv` превращает выгрузку «Базы льгот» в CSV в `benefits.json`.
- **Автопубликация:** при каждом изменении в ветке `main` сайт пересобирается и обновляется на GitHub Pages.

## Что нужно решить автору

1. **Пенсионный возраст.** Сейчас 63 года. Для женщин по закону 61 год, а пол на сайте не спрашивается. Варианты: оставить 63, поставить 61 или добавить вопрос о поле.
2. **Пенсионеры видят мало льгот.** Строки ГСП, налоговые и большинство других отмечены сегментом «Взрослый». Пенсионеру показываются только льготы с сегментом «Любой». Нужно решить, какие строки относятся и к пенсионерам, и указать в колонке «Сегмент»: «Взрослый, Пенсионер».
   - Колонки «С детства» и «Инструкция» больше не обязательны: они определяются по названию льготы.
3. **Неточность на границах возраста.** Год рождения без даты: если человеку в этом году исполняется ровно 7 лет, показываются и I–III, и «ребёнок до 7 лет». Такая же неточность на границе 18 лет и пенсионного возраста.
4. **Названия льгот для людей старше 50.** Например, «ГСП по инвалидности: взрослый (от общего заболевания)» трудно понять без подготовки. Предлагаю «Пособие по инвалидности». Названия меняются в таблице.
5. **Строки без размера:** пособие по уходу за человеком с I группой, социальная выплата ГФСС. На сайте они показываются с тем текстом, который есть в таблице.
6. **Инструкции для остальных льгот.** Пока «Как получить» показывает текст из колонки «Как получить».
7. **Номер WhatsApp и аккаунт Telegram оператора.**

## Как править сайт

Откройте файл на GitHub, нажмите карандаш, затем **Commit changes**. Через 1–2 минуты изменения будут на сайте.

| Что | Файл |
|---|---|
| Льготы | `public/data/benefits.json` |
| Пошаговые инструкции | `public/data/guides.json` |
| WhatsApp, Telegram, пенсионный возраст | `public/data/config.json` |
| Надписи на сайте (рус.) | `public/i18n/ru.json` |
| Казахский перевод | `public/i18n/kk.json` |

Подробнее о полях и правилах JSON написано в `README.md`.

## Следующие шаги

1. После правок в таблице: Файл → Скачать → CSV и `npm run import:csv -- файл.csv` (или прислать CSV в чат).
2. Добавить контакты оператора в `config.json`.
3. Решить вопросы из раздела «Что нужно решить автору».
4. Заполнить `kk.json` и включить казахский язык: добавить `"kk"` в `languages` в `config.json`.
